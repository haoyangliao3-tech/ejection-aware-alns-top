# Reproduction scripts

Install the exact reported environment before running experiments:

```bash
python -m pip install -e ".[reproduction,dev]"
```

Place the Dang-82 instance files as described in `benchmarks/README.md`. The original study used seeds 0-3. Fixed-iteration and symmetric wall-clock batches used two process workers; the final GRASP/ILS/VNS/PyVRP runtime-budget batch used one worker and one internal thread.

## Fixed-iteration Ejection ON/OFF

```bash
python scripts/experiments/run_ejection_benchmark.py \
  --dataset dang --iterations 2500 --seeds 0 1 2 3 \
  --workers 2 --mode compare --output-dir outputs/fixed_ejection
```

## Fixed-iteration GRASP/ILS/VNS

```bash
python scripts/experiments/run_horizontal_baselines.py \
  --benchmark-root benchmarks --algorithms grasp ils vns \
  --iterations 2500 --seeds 0 1 2 3 --workers 2 \
  --output-dir outputs/fixed_comparators
```

## Symmetric wall-clock Ejection ON/OFF

Run this command once with `--ejection on` and once with `--ejection off`, using the fixed-iteration JSON produced above:

```bash
python scripts/experiments/run_ejection_off_time_matched.py \
  --reference-json outputs/fixed_ejection/REFERENCE.json \
  --benchmark-root benchmarks --reference-iterations 2500 \
  --ejection on --wall-clock-cooling --seeds 0 1 2 3 \
  --workers 2 --output-dir outputs/symmetric_on
```

## Runtime-budget GRASP/ILS/VNS/PyVRP

```bash
python scripts/experiments/run_time_matched_baselines.py \
  --reference-json outputs/fixed_ejection/REFERENCE.json \
  --benchmark-root benchmarks --budget-mode instance_seed_mean \
  --algorithms grasp ils vns pyvrp --reference-iterations 2500 \
  --seeds 0 1 2 3 --workers 1 \
  --output-dir outputs/runtime_comparators
```

## Runtime-budget Kim augmented LNS

```bash
python scripts/experiments/run_selected_algorithm_experiment.py \
  --algorithm kim_alns --protocol time_matched \
  --benchmark-root benchmarks \
  --budgets data/results/csv/runtime_budgets.csv \
  --seeds 0 1 2 3 --workers 2 \
  --output-dir outputs/runtime_kim
```

## Focused experiments and figures

- `run_sensitivity_history.py`: nine-instance K-L sensitivity experiment.
- `run_review_mechanism_experiments.py`: focused mechanism/component experiment and audit logging.
- `figures/`: plotting scripts for the data-driven manuscript figures.
- `analysis/export_result_tables.py`: deterministic JSON-to-CSV export.
- `analysis/validate_reported_results.py`: complete QA and statistical reconciliation.

`REFERENCE.json` denotes the timestamped JSON generated by the fixed-iteration runner. Runtime comparisons are hardware-sensitive; use isolated execution and the worker/thread settings above.
