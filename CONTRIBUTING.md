# Contributing

Bug reports, reproducibility reports, and focused pull requests are welcome.

1. Create a branch from `main`.
2. Install the development environment with `python -m pip install -e ".[dev]"`.
3. Add or update tests for behavioral changes.
4. Run `python -m pytest` before opening a pull request.

Please do not commit benchmark collections, raw experimental outputs, manuscript files, personal information, or credentials. For algorithmic changes, describe the affected operator, the expected behavior, and the validation performed.
